Matunga
Spec Completa

Jogo de tabuleiro 6×6 com cavalos de xadrez. Vence quem formar um L-tetromino com 4 peças. Documento de referência para implementação por IA.

6×6 board 2 jogadores 12 peças totais movimento: cavalo vitória: L-tetromino
01 tabuleiro inicial
Setup: 6 × 6, peças nas colunas 0 e 5
O tabuleiro tem 6 colunas (0–5) e 6 linhas (0–5). Todas as 12 peças começam fixas nas colunas extremas. As células internas (colunas 1–4) começam vazias. As peças alternam entre jogadores em cada linha.
🦄 Unicórnio — posições iniciais
Col 0: linhas 0, 2, 4  |  Col 5: linhas 1, 3, 5
(0,0)(2,0)(4,0)(1,5)(3,5)(5,5)
🐴 Cavalo — posições iniciais
Col 0: linhas 1, 3, 5  |  Col 5: linhas 0, 2, 4
(1,0)(3,0)(5,0)(0,5)(2,5)(4,5)
Estrutura de dados recomendada
Representar o tabuleiro como array 6×6 de strings: "" vazio, "U" unicórnio, "H" cavalo. Coordenadas: board[row][col].
const initBoard = () => {
  const b = Array.from({length: 6}, () => Array(6).fill(""));
  // coluna 0
  [0,2,4].forEach(r => b[r][0] = "U"); // unicórnio
  [1,3,5].forEach(r => b[r][0] = "H"); // cavalo
  // coluna 5
  [1,3,5].forEach(r => b[r][5] = "U");
  [0,2,4].forEach(r => b[r][5] = "H");
  return b;
};
02 regra de movimento
Movimento idêntico ao cavalo de xadrez (L-knight)
A peça salta em L: 2 casas em uma direção + 1 casa perpendicular (ou vice-versa). 8 destinos possíveis no centro; menos nas bordas. O salto ignora peças no caminho. O destino deve estar vazio — qualquer peça no destino (própria ou adversária) torna o movimento ilegal. Não há captura. As 12 peças permanecem no tabuleiro do início ao fim.

Deltas de movimento

const DELTAS = [
  [-2,-1], [-2,+1],
  [-1,-2], [-1,+2],
  [+1,-2], [+1,+2],
  [+2,-1], [+2,+1],
];

Movimentos válidos de (r,c)

function validMoves(b, r, c) {
  const player = b[r][c];
  return DELTAS
    .map(([dr, dc]) =>
      [r+dr, c+dc])
    .filter(([nr, nc]) =>
      nr >= 0 && nr < 6 &&
      nc >= 0 && nc < 6 &&
      b[nr][nc] === "");  // apenas vazio — qualquer peça bloqueia
}

03 condição de vitória
L-tetromino com 4 peças suas em qualquer orientação
Vence o jogador que, após qualquer jogada, tiver 4 ou mais de suas peças formando um L-tetromino (incluindo J-tetromino = espelho do L). São 8 orientações válidas. A verificação deve checar todas as 8 após cada lance. Não é necessário que sejam exatamente 4 — se você tiver 5 peças e 4 delas formam um L, você vence.

As 8 orientações válidas do L-tetromino:

// Todas as 8 orientações: offsets [dRow, dCol] relativos ao canto superior esquerdo
const L_SHAPES = [
  [[0,0],[1,0],[2,0],[2,1]], // L normal       ↓→
  [[0,1],[1,1],[2,0],[2,1]], // J normal       ↓←
  [[0,0],[0,1],[0,2],[1,0]], // L rot 90°CW    →↓
  [[0,0],[0,1],[0,2],[1,2]], // J rot 90°CW    →↑
  [[0,0],[0,1],[1,1],[2,1]], // L rot 180°     ↑→
  [[0,0],[0,1],[1,0],[2,0]], // J rot 180°     ↑←
  [[0,0],[1,0],[1,1],[1,2]], // L rot 270°     ↑→ (invertido)
  [[0,2],[1,0],[1,1],[1,2]], // J rot 270°     ↑← (invertido)
];

function checkWin(board, player) {
  const positions = [];
  for (let r = 0; r < 6; r++)
    for (let c = 0; c < 6; c++)
      if (board[r][c] === player) positions.push([r,c]);

  const set = new Set(positions.map(([r,c]) => `${r},${c}`));

  for (const [r, c] of positions) {
    for (const shape of L_SHAPES) {
      if (shape.every(([dr, dc]) => set.has(`${r+dr},${c+dc}`)))
        return true;
    }
  }
  return false;
}

Turno
  • O jogador deve mover uma peça (sem passar a vez)
  • Move exatamente uma peça por turno
  • O destino deve ser vazio — peça própria ou adversária bloqueia igualmente
  • Após mover, verifica-se vitória para o jogador atual
Bloqueio posicional
  • Qualquer peça (própria ou adversária) bloqueia o destino igualmente
  • As 12 peças nunca saem do tabuleiro — contagem sempre 6+6
  • O centro fica congestionado com o avanço do jogo
  • Ocupar a célula que o adversário precisa para completar o L é o bloqueio fundamental
Empate / sem movimentos
Se um jogador não tiver nenhum movimento válido (todas as suas peças completamente cercadas), a vez passa ao adversário. Se nenhum dos jogadores puder mover, o jogo termina em empate. Como não há capturas, o número de peças nunca muda — ambos mantêm 6 peças até o fim. O congestionamento do centro pode levar a posições de bloqueio mútuo.
05 técnicas estratégicas
Centralização fundamento
Peças nas bordas têm 2 movimentos possíveis; no centro, até 8. A prioridade nas primeiras jogadas é levar cavalos para as colunas 2–3 e linhas 2–3. Um cavalo em (2,2) ou (3,3) pode alcançar 8 casas; um em (0,0) apenas 2. Abrir com (0,0)→(1,2) ou (2,0)→(3,2) coloca peças no centro rapidamente.
Proto-L (3 de 4) ataque
Construa as 3 peças de um L antes de precisar da 4ª. Um "proto-L" força o adversário a bloquear a célula de completude ou perder. Identifique todas as 8 variantes — qual é mais rápida de completar com seus cavalos atuais? Priorize formas onde a célula faltante está a 1 jogada de uma peça sua.
Garfo (Fork) ataque
A técnica mais poderosa: ameace dois L diferentes simultaneamente. O adversário pode bloquear apenas um. Para criar um fork, posicione uma peça que seja a peça faltante de dois proto-L distintos ao mesmo tempo. O adversário fica em xeque-fork e perde na próxima jogada.

Exemplo: Se você tem peças em (1,2), (2,2), (3,2) — coluna vertical de 3 — e consegue colocar uma peça em (3,3), forma o L-normal. Mas se simultaneamente você tem (2,1), (2,2), (2,3) — linha horizontal —, uma peça em (3,1) completa outro L. Se essas duas ameaças existirem ao mesmo tempo, é um fork.
Congestionamento do Centro avançado
Como não há captura, o centro do tabuleiro enche com o tempo. Uma estratégia válida é avançar suas peças para as células que o adversário precisa — não para completar seu próprio L, mas para negar o espaço. Isso força o adversário a trabalhar nas bordas, onde o cavalo tem menos mobilidade. Risco: se você congesta o centro com suas próprias peças, também se limita. Use o congestionamento para direcionar o adversário, não para paralisar o jogo.
Defesa: Bloqueio Preventivo defesa
Identifique proto-L do adversário e ocupe a célula de completude antes que ele possa. Mova uma sua peça para essa célula (mesmo que o movimento pareça neutro ofensivamente). Sua peça naquela célula é um bloqueador permanente enquanto estiver lá — o adversário não tem como removê-la. Priorize bloquear o proto-L mais avançado (faltando 1 peça).
Contagem de Jogadas (Tempo) cálculo
Cada peça nas bordas leva 2–3 movimentos para chegar ao centro. Antes de construir um L, conte: quantos lances faltam para completá-lo? Quantos lances faltam para o adversário completar o dele? Se o adversário chega em N−1 jogadas, você precisa bloquear agora. Priorize sempre o caminho mais curto para o L mais próximo de ser completado.
Isca (Decoy) avançado
Construa um proto-L visível para atrair o bloqueador do adversário para uma região, enquanto o L real está sendo montado silenciosamente em outro lado do tabuleiro. Peças de xadrez têm mobilidade: é fácil construir ameaças em múltiplas regiões ao mesmo tempo. O adversário tende a reagir ao mais óbvio — use isso.
06 implementação de IA (bot)
Função de avaliação de estado (heurística)
Para cada estado do tabuleiro, o score do bot deve considerar:
  • +1000: vitória imediata (L completo formado)
  • +50 × N: N proto-L (3 de 4 células preenchidas)
  • +10 × N: N pares-de-L (2 de 4 células em posição)
  • +5 × moves: número de movimentos disponíveis (mobilidade)
  • −30 × adversário_proto_L: proto-L do adversário (urgência de bloqueio)
  • +8 × (3 − dist_centro): peças mais próximas do centro
  • +20: jogada que cria fork (duas ameaças simultâneas)
function evaluate(board, me, opp) {
  let score = 0;
  const center = [2.5, 2.5];

  for (let r = 0; r < 6; r++) {
    for (let c = 0; c < 6; c++) {
      if (board[r][c] === me) {
        // distância ao centro — menor = melhor
        const dist = Math.abs(r-center[0]) + Math.abs(c-center[1]);
        score += 8 * (5 - dist);
      }
    }
  }

  // contar proto-L e pares para ambos os jogadores
  score += 50 * countProtoL(board, me);
  score -= 30 * countProtoL(board, opp);
  score += 10 * countPairL(board, me);
  score += 5  * countMoves(board, me);
  score -= 5  * countMoves(board, opp);
  return score;
}

// countProtoL: verifica quantos L_SHAPES têm 3/4 células preenchidas pelo jogador
function countProtoL(board, player) {
  let count = 0;
  for (let r = 0; r < 6; r++)
    for (let c = 0; c < 6; c++)
      for (const shape of L_SHAPES) {
        const filled = shape.filter(([dr,dc]) =>
          r+dr<6 && c+dc<6 && board[r+dr][c+dc]===player).length;
        if (filled === 3) count++;
      }
  return count;
}
Minimax com alpha-beta (profundidade recomendada: 3–4)
Para dificuldade média, use minimax com profundidade 3 (rápido). Para dificuldade difícil, profundidade 4–5 com poda alpha-beta. O espaço de estados do Matunga é limitado — o jogo tende a terminar em 15–30 lances. Iterative deepening com time limit de 1s é a abordagem mais robusta para produção.

  • Histórico de movimentos em notação (r,c)→(r,c)
Modos de jogo
  • 🧑 vs 🧑 — dois jogadores local
  • 🧑 vs 🤖 — jogador vs bot (3 dificuldades)
  • 🤖 vs 🤖 — simulação automática
  • Opção de desfazer jogada (undo) 1×

  • CSS Grid para o tabuleiro (6×6 natural)

  • Sem libs externas além de animação (Framer ou CSS)
